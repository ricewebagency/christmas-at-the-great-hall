<INSTRUCTIONS>
## Project Rules
- Always put JavaScript in separate `.js` files under `src/js/`.
- Use Tailwind CSS only.
- Do not write custom CSS unless it is truly impossible with Tailwind. If needed, ask first. If so, put custom CSS in seperate `.css` files under `src/css/`.
- Never run build commands yourself. The user runs `npm run dev`, which auto-builds and copies files to docs/ folder.
- Never publish your changes to the docs/ folder. Changes will already go there via the `npm run dev` command.
</INSTRUCTIONS>
